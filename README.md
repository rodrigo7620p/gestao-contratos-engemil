# Gestão de Contratos ENGEMIL

Sistema web (Streamlit + Turso) para centralizar contratos, aditivos,
garantias, ARTs, licitações, SESMT, documentos padronizados e as
comunicações automáticas por e-mail relacionadas a essas rotinas.

Publicado em: <https://gestao-contratos-engemil.streamlit.app/>

## Documentação

- **[MANUAL_DO_SISTEMA.md](MANUAL_DO_SISTEMA.md)** — mapa da plataforma e
  manual de uso completo (mapa do menu, perfis e permissões, instruções
  módulo a módulo, comunicações automáticas por e-mail e administração
  técnica/hospedagem). Também publicado como página web:
  <https://claude.ai/code/artifact/799b5250-ffd6-4e82-b449-137de7c7cffd>
- **[VERSAO.txt](VERSAO.txt)** — changelog técnico, uma entrada por versão.
- **[CLAUDE.md](CLAUDE.md)** — instruções de manutenção do projeto.

Os arquivos `GESTAO_LICITACOES.md` e `GESTAO_SESMT.md` registram o
histórico de decisões técnicas desses dois módulos e continuam no
repositório como referência; o estado atual de uso de ambos já está
descrito no manual acima.
